Manual app estimates

Enter weather and AQI, change precipitation, and see the heat-index study warning.

Download MP4 · Try the app

Steps shown in the recording
  1. Start with 85°F, 55% humidity, AQI 60 and 17:00 DC time. Read the estimated chance of low network demand.
  2. Change precipitation to 0.4 inches per hour. The model estimate updates immediately.
  3. Set temperature to 100°F and humidity to 39%. The calculated heat index is 108.5°F, so the app shows that a study threshold is exceeded.
  4. Restore the original manual example. Loading a live DC forecast is a separate action.

Pipeline and research charts

A historical recording of the pipeline, model comparisons, curves, calibration and simulated time shifts.

Download MP4 · Charts

What the recording covers
  1. Shared DC data feed historical evaluation and a separate all-years browser refit. Only forecast inputs trigger hour comparison.
  2. Five model variants evaluated on the 2024 test set.
  3. ROC and precision–recall curves, followed by probability calibration.
  4. Net time-shift scenarios, including cancellation losses and the assumed transfer of shifted demand.

The app estimates aggregate bike-share demand. The model evaluation describes historical scores and simulated recovery. Live forecast accuracy and actual ride recovery have not been measured.
