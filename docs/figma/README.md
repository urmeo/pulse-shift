# Pipeline design

[Figma source](https://www.figma.com/design/yhY22TCHa8m8mhBi1Z4RCw?node-id=2-2) · [Mobile frame](https://www.figma.com/design/yhY22TCHa8m8mhBi1Z4RCw?node-id=2-3) · [Previous design](https://www.figma.com/design/yhY22TCHa8m8mhBi1Z4RCw?node-id=48-2)

Both layouts use editable Figma text, shapes and connectors. Cyan arrows carry data or model outputs. Dashed coral arrows apply the study limits to candidate hours. The desktop view uses a gray branch for the observational AQI analysis. Seoul uses its own data and model.

The README, app and results page use the same native [desktop SVG](../../results/figures/pipeline.svg) and [mobile SVG](../../results/figures/pipeline-mobile.svg) exports. Edit the corresponding Figma frames and export them again when the pipeline changes.
